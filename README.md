# 词间 · 小说背单词

用完整中文故事理解英语词义。当前版本收录一篇原创六级职场短篇《最后一页，请保留我的名字》。

## 使用

下载项目后，用浏览器打开 `index.html`，点击“开始阅读”。无需安装依赖或运行构建命令；也可以交给静态网站服务提供在线访问。

- 完整故事：39段，54个不同目标词、56处英文及中文释义标注。
- 点词卡：音标、故事语境、原词表释义、英美发音、生词本、熟悉度标记。
- 学习模式：显示中英、隐藏中文、英文填空、字号调整。
- 词表：本篇词汇、5518词六级词表及生词本，支持搜索和筛选。
- 正文下载：点击“下载正文 PDF”直接保存5页PDF，保留中英标注；PDF已内嵌网页。独立副本在 `downloads/s001.pdf`。
- 学习记录：保存在当前浏览器，可备份和恢复。网页来源地址、浏览器或设备改变后，记录可能分开，请先备份。当前没有账号系统或云同步。

发音使用浏览器/系统可用语音。本机优先美音Samantha、英音Daniel，排除特殊音效声音；两者采用100%网页音量、0.9倍语速及正常音高。不同设备音色和实际响度可能不同。

小说覆盖54/5518（0.98%）与读者自己已掌握的词数分别展示；本项目不代表全词表已由小说覆盖。
